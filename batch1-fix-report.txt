### C.1 `verify_scanner.py`（T-A）

**（1）新增原因码常量**（`EXPECTED_SCAN_PAGES` 之后）

```python
REASON_SITE_MISSING = "SITE_MISSING"     # site/ 不存在 —— 构建产物缺失
REASON_ZERO_HIT     = "ZERO_HIT"         # 目录在，但没有任何页面出现 def scan(
REASON_DUPLICATE    = "DUPLICATE"        # 某页出现多份 scan()
REASON_SET_MISMATCH = "SET_MISMATCH"     # 页面集合与 EXPECTED_SCAN_PAGES 不等
REASON_OK           = "OK"
```

**（2）新增取数函数**（None 与 {} 严格区分）

```python
def scan_page_counts(site_dir):
    p = pathlib.Path(site_dir)
    if not p.is_dir():
        return None                      # 构建产物缺失
    counts = {}
    for f in sorted(p.glob("*.html")):
        txt = f.read_text(encoding="utf-8", errors="ignore")
        n = len(re.findall(r"^def scan\(conn, mark\):", txt, re.M))
        if n:
            counts[f.name] = n
    return counts                        # 空 dict = 产物在但零命中
```

**（3）新增唯一判定入口**（复用 `html_pages_ok()` 做判定，`dup` 仅用于归因）

```python
def judge_site_pages(site_dir):
    counts = scan_page_counts(site_dir)
    if counts is None:
        return (False, REASON_SITE_MISSING,
                f"目录不存在：{site_dir}（先跑 md2html.py 生成 site/）", counts)
    if not counts:
        return (False, REASON_ZERO_HIT,
                f"目录内没有任何页面出现 def scan(（应为 {EXPECTED_SCAN_PAGES}）", counts)
    # 判定本身复用 html_pages_ok()，不复制一套集合逻辑
    ok, why = html_pages_ok(counts)
    if ok:
        return True, REASON_OK, why, counts
    # 归因专用：判定结果已由 html_pages_ok() 给出，这里再查一次 dup
    # 只是为了把"失败"分类到 DUPLICATE / SET_MISMATCH，**不参与判定**。
    dup = {k: counts[k] for k in sorted(counts) if counts[k] != 1}
    if dup:
        return False, REASON_DUPLICATE, f"某页出现多份 scan()：{dup}；{_set_diag(counts)}", counts
    _, missing, extra = _page_diff(counts)
    return False, REASON_SET_MISMATCH, f"缺 {missing}，多 {extra}", counts
```

`_set_diag()` 在集合本身正常时返回 `集合诊断：无差异`，否则 `集合诊断：缺 [...]，多 [...]`；`counts` 恒为完整取数结果。

**（4）主流程改为无条件调用**（删除 `if SITE.is_dir()` 与 `if html_counts:` 两层旁路）

改动前：

```python
html_counts = {}
if SITE.is_dir():
    ...（逐页扫 scan()）
    print(f"  HTML：含 scan() 定义的页面 {...}")
else:
    print("  HTML：site/ 不存在，跳过（先跑 md2html.py）")
    pages, total_html = [], 0
...
if html_counts:                                   # ← 空集合旁路（本次要修的 fail-open）
    ok_pages, why_pages = html_pages_ok(html_counts)
    check("HTML 每页至多 1 份 scan()", all(v == 1 for v in html_counts.values()))
    check("HTML 含 scan() 的页面集合与 EXPECTED_SCAN_PAGES 精确相等", ok_pages)
```

改动后：

```python
ok_pages, page_code, why_pages, html_counts = judge_site_pages(SITE)
print(f"  页面取数：{html_counts if html_counts else '{}'}")
print(f"  页面集合判定：[{page_code}] {why_pages}")
...
# 无条件判定：空集合 / 缺目录都会落到具体原因码上，不再有"集合为空就跳过"的旁路
check("HTML 有页面被检出（site 存在，且至少一页含 scan()）",
      page_code not in (REASON_SITE_MISSING, REASON_ZERO_HIT))
check("HTML 页面集合 = EXPECTED_SCAN_PAGES 且每页恰 1 份", ok_pages)
```

同时**删除**了 `all(v == 1 for v in {}.values())` 这个空真表达式作为独立检查项（空集合不再可能进入该分支，改由原因码兜住）。

**（5）新增第 4b 节：6 条流程级用例**（`tempfile.mkdtemp()` 造现场，`finally` 中 `shutil.rmtree` 清理，**不动 `site/`**）
